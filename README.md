# 🏦 Banco Python

Um sistema bancário simples desenvolvido em Python, com o objetivo de praticar conceitos básicos de programação, como estruturas condicionais, laços de repetição, listas e operações matemáticas.

## 📌 Funcionalidades

O sistema possui um menu interativo com as seguintes opções:

- **Consultar saldo:** exibe o saldo atual da conta.
- **Depositar:** permite adicionar valores positivos ao saldo.
- **Sacar:** permite retirar dinheiro respeitando as regras do sistema.
- **Ver extrato:** apresenta todas as movimentações realizadas.
- **Sair:** encerra a execução do programa.

## ⚙️ Regras do sistema

- Não é permitido realizar depósitos com valores negativos ou iguais a zero.
- Não é permitido realizar saques com valores negativos ou iguais a zero.
- O saque não pode ser maior que o saldo disponível.
- O limite máximo por saque é de R$ 500,00.
- São permitidos no máximo 3 saques durante a execução do programa.
- Todas as movimentações são registradas no extrato.

## 🛠️ Tecnologias utilizadas

- Python 3

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no VS Code ou em outro editor.
3. Execute o arquivo Python pelo terminal:

```bash
python main.py
```
